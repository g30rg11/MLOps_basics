# MLOps Basics

## Автор

Георгий Пуськов

## Инструменты

- Python 3.12
- uv — управление окружением и зависимостями
- Ruff — проверка и форматирование кода
- ty — проверка типов

## Установка и запуск

```bash
uv sync
uv run python main.py
```

## Проверки

```bash
uv run ruff check .
uv run ruff format --check .
uv run ty check
```
