# MLOps Basics

## Автор

Георгий Пуськов

## Инструменты

- Python 3.12
- uv — управление окружением и зависимостями
- Ruff — проверка и форматирование кода
- ty — проверка типов
- DVC — версионирование данных и управление пайплайном

## Установка и запуск

```bash
uv sync
uv run python main.py
```

## Проверки

```bash
uv run ruff check .
uv run ruff format --check .
uv run ty check
```

## Пайплайн DVC

Исходные данные: `data/substances.csv`.

1. `calculate` — расчёт количества вещества с сохранением в `data/results.csv`.
2. `summarize` — создание отчёта `reports/summary.json`.

Данные и результаты хранятся через DVC, код и метаданные — в Git.

Запуск пайплайна, просмотр графа и проверка состояния:

```bash
uv run dvc repro
uv run dvc dag
uv run dvc status
```

Отправка и получение данных:

```bash
uv run dvc push
uv run dvc pull
```

Remote настроен на локальную папку вне репозитория.
Для работы на другом компьютере необходимо настроить путь
к доступной копии хранилища и выполнить `uv run dvc pull`.
