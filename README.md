## Инструменты

- Python 3.12
- uv — управление окружением и зависимостями
- Ruff — проверка и форматирование кода
- ty — проверка типов
- DVC — версионирование данных и управление пайплайном
- PyTorch — построение и обучение нейросети
- scikit-learn — датасет Wine и разделение выборки
- pytest — запуск тестов
- Hypothesis — property-based тестирование
- pytest-cov — измерение покрытия кода тестами

## Установка и запуск

```bash
uv sync
uv run python main.py
```

## Проверки

```bash
uv run ruff check .
uv run ruff format --check .
uv run ty check
```

## Пайплайн DVC

Исходные данные: `data/substances.csv`.

1. `calculate` — расчёт количества вещества с сохранением в `data/results.csv`.
2. `summarize` — создание отчёта `reports/summary.json`.

Данные и результаты хранятся через DVC, код и метаданные — в Git.

Запуск пайплайна, просмотр графа и проверка состояния:

```bash
uv run dvc repro
uv run dvc dag
uv run dvc status
```

Отправка и получение данных:

```bash
uv run dvc push
uv run dvc pull
```

Remote настроен на локальную папку вне репозитория.
Для работы на другом компьютере необходимо настроить путь
к доступной копии хранилища и выполнить `uv run dvc pull`.

## ML-пайплайн и тестирование

Задача — классификация образцов Wine по 13 признакам химического
анализа. Датасет содержит 178 объектов и 3 класса.

Пайплайн включает разделение данных, нормализацию по обучающей
выборке, DataLoader, нейросеть, обучение, оценку и сохранение модели.
Вместе с весами сохраняются параметры нормализации.

Запуск обучения на CPU:

```bash
uv run python -m mlops_homework.train --epochs 20 --output-dir artifacts
```

Запуск всех тестов:

```bash
uv run python -m pytest -v
```

Запуск отдельной категории:

```bash
uv run python -m pytest -v -m unit
uv run python -m pytest -v -m e2e
```

Запуск с покрытием в PowerShell:

```powershell
uv run python -m pytest -v --cov=mlops_homework --cov-config="$PWD\.coveragerc" --cov-report=term-missing
```

Реализованы unit, property-based, metamorphic, integration,
smoke и e2e тесты. Тест переобучения на маленьком батче отмечен
маркером `slow`.

Результат проверенного запуска: 14 тестов пройдены,
покрытие строк пакета `mlops_homework` — 90%.
